# Santhosh Developer Portfolio

A responsive developer portfolio built with React, TypeScript, Vite and plain CSS.

## Run locally

1. Install Node.js (LTS).
2. Extract this folder.
3. Open a terminal inside the project folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL printed by Vite (usually http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```

The production website is generated in `dist/`.

## Before publishing

Update these items in `src/App.tsx`:

- `YOUR_EMAIL@example.com` with your professional email address.
- LinkedIn URL with your actual profile URL.
- GitHub URL with your actual profile URL.
- Confirm employer name, employment dates, role title and project descriptions.
- Add only screenshots, links and project details that you have permission to publish.

## Deploy to Vercel

1. Push this project to a new GitHub repository.
2. Sign in to Vercel and import that repository.
3. Keep the default Vite build settings:
   - Build command: `npm run build`
   - Output directory: `dist`
4. Deploy.

## Important portfolio accuracy note

The project descriptions are intentionally high-level. Do not publish proprietary company source code, customer information, credentials, internal API details or screenshots without permission. Clearly distinguish professional experience from independently built portfolio demos.
